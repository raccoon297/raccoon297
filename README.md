## Engineering Focus

- 문제 정의부터 데이터 처리, 모델 학습, 정량 평가와 시각화까지 하나의 실행 흐름으로 구성합니다.
- 평균 성능만 제시하지 않고 실패 사례, 제약 조건과 해석상의 한계를 함께 기록합니다.
- 데이터 처리, 모델과 평가 로직을 분리해 확장과 유지보수가 쉬운 ML 시스템을 구현합니다.
